1. Назначение документа

Настоящая политика описывает порядок работы с данными посетителей сайта проекта роботизированного деревообрабатывающего станка для профилирования изделий.

2. Текущий режим сайта

На дату этой редакции сайт не содержит форм обратной связи, личного кабинета, аналитических счетчиков, рекламных пикселей, карт, видеоплееров и сервисов авторизации. При просмотре страниц сайт не запрашивает имя, номер телефона, адрес электронной почты или иные данные посетителя.

Посетитель может самостоятельно направить письмо по адресу safinov03@mail.ru. Содержание письма и контактные данные, указанные отправителем, используются для рассмотрения обращения и ответа на него.

4. Технические данные

Сайт не использует собственные cookie для аналитики или рекламы. Браузер может сохранять технический кэш статических файлов в соответствии со своими настройками. Для отображения текста используются внешние файлы шрифта.

5. Изменение функций сайта

До подключения формы обратной связи, аналитики или других внешних сервисов политика будет дополнена сведениями о составе обрабатываемых данных, целях обработки и способах обращения по вопросам конфиденциальности.

6. Вопросы по политике

По вопросам, связанным с настоящей политикой, можно обратиться по адресу safinov03@mail.ru.
